# coreservices.shop | Map tiles for CS Config

The satellite map that CS Config draws behind the places of your scripts. The menu loads these tiles only while an admin has the map open. Players never download them.

`tiles/<zoom>/<x>/<y>.jpg`, zoom 0 to 5, 256 px each. The tiles come from [meesvrh/GTAV-Map-Tiles](https://github.com/meesvrh/GTAV-Map-Tiles). The imagery belongs to Rockstar Games.

Setup and everything else: coreservices.shop/docs
